    Agent → hôte local → noyau MCP → adaptateurs FTP/FTPS/SFTP → serveur distant. La configuration alimente les contrôles du noyau. La vue cible y ajoute des plans et un journal durable.

      Frontière de qualification. Le contexte retenu est un serveur MCP stdio local pour une équipe supervisée. Authentification et isolation d’un service partagé ne sont pas démontrées. Les garanties sont à préciser par protocole, serveur et mode d’exploitation.

      Comportement cible

        FAIT OBSERVÉ DANS LA BASELINE

        Idempotence ≠ exactly once. Retrouver une même opération évite de rejouer aveuglément une demande connue. Un crash entre l’écriture distante et le journal peut laisser un état inconnu : la reprise doit d’abord le réconcilier, ou rester bloquée faute de preuve.
