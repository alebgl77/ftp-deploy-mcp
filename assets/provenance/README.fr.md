# Provenance des bannières du README

[English](./README.md) | **Français**

La [bannière française](../banner-fr.png) et la [bannière anglaise](../banner-en.png)
ont été générées avec ChatGPT Image le **2026-09-09 (Europe/Paris)**. L'image
française a été générée en premier ; l'image anglaise a été produite en
modifiant son sous-titre avec l'image française comme référence.

Les prompts exacts sont conservés sans traduction ni réécriture :

- [Prompt de génération de la bannière française](./banner-fr.prompt.txt).
- [Prompt de modification du sous-titre anglais](./banner-en.prompt.txt).

Ces illustrations expriment l'orientation du projet. Elles ne certifient ni
la sécurité, ni l'atomicité, ni la disponibilité, ni l'aptitude au déploiement
autonome en production. Elles ne comportent aucune version publiée, aucun
compteur de tests et aucun résultat de performance. Consultez le
[modèle de sécurité](../../docs/SECURITY-MODEL.fr.md) pour les garanties et
limites réelles.

Les images et cette provenance restent dans le dépôt, hors du paquet npm.
Les URL d'images des README pointent vers le dépôt pour que les lecteurs du
paquet puissent également les charger.
